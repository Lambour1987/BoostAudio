# BoostAudio

## Over dit project

BoostAudio is een persoonlijk C++-project waarin ik onderzoek hoe de Windows Audio API werkt.

Het uiteindelijke doel is om een applicatie te bouwen waarmee het volume softwarematig verder verhoogd kan worden dan de standaard volumeregeling van Windows.

Het project bevindt zich nog in ontwikkeling en wordt gebruikt om ervaring op te doen met Windows-programmering, audioverwerking en modern C++.

> 🚧 **Status:** In ontwikkeling

---

## Huidige functionaliteit

Op dit moment kan de applicatie:

- Audio-uitvoerapparaten ophalen
- Beschikbare uitvoerapparaten weergeven
- Het huidige volume uitlezen
- Het mastervolume instellen tussen 0.0 en 1.0 via de Windows Core Audio API

Deze functionaliteit vormt de basis voor de volgende ontwikkelstappen.

---

## Geplande functionaliteit

- Softwarematige volumeversterking boven de standaard Windows-limiet
- Eenvoudige grafische gebruikersinterface
- Wisselen tussen audio-uitvoerapparaten
- Instellingen opslaan
- Betere foutafhandeling
